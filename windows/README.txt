MASSIVE Attract Cabinet — Windows 10/11 x64

1. Extract the complete ZIP into a folder.
2. Run Install.cmd. It copies the application to your LocalAppData folder and opens Windows Screen Saver Settings. No administrator access is required.
3. Actual game footage is the default. Choose Settings to select a level or archive recording. Optional Interpretations are available in the second tab. Open Service and click Save settings to save the selection. Use Windows' own timeout and sign-in settings.
4. Choose Preview. Move the mouse or press a key to exit.

Requires Microsoft Edge WebView2 Evergreen Runtime (included on many current Windows systems): https://developer.microsoft.com/en-us/microsoft-edge/webview2/
The package includes its .NET runtime and all screen saver media; ordinary playback works offline. Catalogue / help links need internet.

This is an unsigned independent application, not a Microsoft product. It presents MASSIVE through an arcade cabinet interface and does not run on Windows 95.

Modes: MASSIVE95.scr /c (settings), /s (all monitors), /p <window-handle> (Windows preview). No lock-screen security is implemented by the app: Windows owns sign-in-on-resume.
Settings remain in LocalAppData\MASSIVE95\BrowserData. To remove: choose a different saver in Windows, close MASSIVE 95, then delete LocalAppData\MASSIVE95. This preserves your other screen saver preferences.

Generative animations are artistic interpretations. Recordings are real Unity captures with a source manifest at wwwroot\sources.json. They loop with a cut unless their provenance says otherwise.
